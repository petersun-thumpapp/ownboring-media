# OwnBoring media

Finished deal-of-the-day shorts for [ownboring.com](https://ownboring.com), published as release downloads so the scheduler can fetch them. Each release is one week's batch. The scripts, and the check that every figure matches the board, live in the app repo.

Figures in each short are the listing broker's, not verified by OwnBoring. OwnBoring is not a broker, lender or adviser. A product of Thump LLC.
