# OwnBoring media

Finished deal-of-the-day shorts for [ownboring.com](https://ownboring.com), kept here so the scheduler can fetch them. Each folder under `weeks/` is one week's batch, named for its Monday. The scripts, and the check that every figure matches the board, live in the app repo.

Figures in each short are the listing broker's, not verified by OwnBoring. OwnBoring is not a broker, lender or adviser. A product of Thump LLC.
